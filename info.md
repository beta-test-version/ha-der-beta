# ha EcoFlow official

Connect EcoFlow inverters to Home Assistant via Modbus TCP.

- All register points exposed as entities (sensor, number, select, switch, button)
- Auto-discovery via mDNS — zero manual configuration
- Product filtering for PowerOcean and STREAM 5000
- Multi-language UI: English, German, French, Italian, Dutch, Polish
- Vendored pymodbus — no external dependencies, installs offline

[Documentation & Source](https://github.com/EcoFlow/modbus-API)
